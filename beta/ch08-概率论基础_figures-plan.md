## 二、出图条目

### 图 1 · fig-bertrand
- 对应知识点：`e2` Bertrand 悖论
- 打分：结构 1 / 过程 2 / 直观 2 / 辨析 1 = 6
- 依据：同一个事件在两种投弦模型下得到 1/3 与 1/4，读者无法在公式层面看出分歧来自哪里
- 插入锚点：`e2-body` · 第 3 段之后
- 前置问题：两条曲线的差别到底出在哪一步？
- 首要教学任务：让两种投弦模型各自对应的密度与尾面积可见
- 关键元素：坐标轴、两条密度 p(x) 与 q(x)、阈值竖线、两条尾面积、出图点标记
- 图后解释：实线为端点随机、虚线为弦心随机；√3 右侧尾面积分别读出 1/3 与 1/4
- 理解检查：为什么两条密度的尾面积不同，而「弦长大于 √3R」这句话没变？（答案：因为概率取决于「随机加在哪个对象上」，两种模型对同一句话给出不同的分母。）
- 失败原因：把两条曲线当成同一模型的两个分量，于是找不到分歧来源。
- 图型与障碍类型：数据分布 → bertrand_area()（B3 hairline area 参考实现）
- 图示规格：
  - 数学对象与符号：x 轴为弦长，p(x) = 1/(π√(1−x²/4))、q(x) = x/2 与材料式号一致
  - 对象之间的关系：两条密度是同一事件在两种模型下的像；阈值 √3R 切出各自的尾
  - 阅读顺序：先轴与阈值竖线，再实线与其尾，最后虚线与其尾
  - 标识职责表：实线 = 端点随机模型（此刻要比较的对象）；虚线 = 弦心随机模型；强调色竖虚线 = 阈值，不是操作；发丝竖线 = 尾面积的单位切片
  - 与正文术语的对应：正文「端点随机 / 弦心随机」两处点名对应实线与虚线
  - 不能暗示的错误结论：不得让读者以为 p 与 q 是同一模型的两个分量，或以为尾面积可由曲线高度直接读出
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— 核过 p(x) 在 x→2⁻ 发散、在 1.915 处出图并已在图注标注截断；两条密度积分都为 1；尾概率 1/3 与 1/4 与正文一致。视觉 —— 第 1 轮两条曲线与全部横档消失（CSS 规则多一个右花括号导致 usvg 放弃后续规则）；修正后第 2 轮通过，无重叠。教学 —— 能回答「分歧来自模型而非计算」；对 e2 的理解障碍有直接作用。

### 图 2 · fig-poisson
- 对应知识点：`e4` Poisson 分布的二项逼近
- 打分：结构 1 / 过程 2 / 直观 1 / 辨析 1 = 5
- 依据：读者知道 n → ∞、np → λ，但看不到分布形态如何稳定下来
- 插入锚点：`e4-body` · 第 1 段之后
- 前置问题：n 增大时柱高为什么不整体变矮？
- 首要教学任务：让 n = 5/20/100 的概率质量逐点逼近 λ^k e^(−λ)/k! 看得见
- 关键元素：三组可数横档、每五档一个小圆点、Poisson(λ) 极限虚线与空心点、k 轴刻度
- 图后解释：三组柱高来自 B(n, 2/n)，虚线来自 Poisson(2)；n 越大两者越贴
- 理解检查：n 从 5 增到 100 时，柱形最高点的位置移动了吗？（答案：基本不动，始终在 k = 2 附近；变的是柱形的宽窄与光滑度。）
- 失败原因：把「形状稳定」误读成「高度不变」，于是找不到收敛的那一项。
- 图型与障碍类型：数据分布 → poisson_bars()（B1 rung bars 参考实现）
- 图示规格：
  - 数学对象与符号：k 轴为取值个数，柱高为 ℙ(X = k)，两组分别标 B(n, 2/n) 与 Poisson(2)
  - 对象之间的关系：三组是同一极限过程的不同阶段；虚线与空心点是极限值
  - 阅读顺序：左 → 中 → 右（n 递增），每格内由柱到虚线
  - 标识职责表：横档 = 1% 概率的可数单位（此刻读者靠它比较高度）；空心点 + 虚线 = 极限值，不是另一组数据；圆点 = 每五档的刻度提示
  - 与正文术语的对应：正文「np = 2 保持不变」对应三格的 p 值标注
  - 不能暗示的错误结论：不得让读者以为 n 只能取这三个值，或以为极限图是另一条拟合曲线
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— 三组概率质量各自和为 1；Poisson(2) 的 k! 取值与材料一致；n = 100 时相邻数值标签改为隔一标一以免重叠。视觉 —— 第 1 轮随 CSS 花括号问题一同丢失全部横档；修正后第 2 轮通过。教学 —— 能回答「收敛的是形状而非高度」；直接针对过程维度。

### 图 3 · fig-memoryless
- 对应知识点：`c11` 经典分布清单（指数分布条目）
- 打分：结构 0 / 过程 1 / 直观 2 / 辨析 1 = 4
- 依据：无记忆性的等式读者会算，但「已经等了 a 不影响再等 b」缺少可见的读数方式
- 插入锚点：`c11-body` · 第 3 段之后
- 前置问题：为什么指数分布被用来描述「没有老化」？
- 首要教学任务：让 ℙ(X ≥ a+b) = ℙ(X ≥ a)·ℙ(X ≥ b) 变成可读的两段区间
- 关键元素：生存函数曲线、时间切片发丝、a 与 a+b 两个关键点、区间括号、恒等式数值
- 图后解释：S(a)·S(b) 与 S(a+b) 数值相等正是无记忆性；图中取 λ = 1 示意
- 理解检查：图 3 里 S(a)·S(b) 与 S(a+b) 哪个大？（答案：相等，这正是无记忆性。）
- 失败原因：把条件化误当成「剩余概率变小」，于是认为无记忆性反直觉。
- 图型与障碍类型：数据分布 → memoryless_line()（B2 hairline line 参考实现）
- 图示规格：
  - 数学对象与符号：t 轴为时间，S(t) = e^(−λt) 为生存函数，a、a+b 为材料中的两个时刻
  - 对象之间的关系：S(a)·S(b) = S(a+b) 的三项在同一张图上各有位置
  - 阅读顺序：曲线 → 两个关键点 → 两段区间括号 → 恒等式
  - 标识职责表：发丝竖线 = 时间切片（面积的可数单位）；括号 = 区间长度标注；强调点 = 两个关键时刻
  - 与正文术语的对应：正文「已经等了 a」对应左侧括号起点
  - 不能暗示的错误结论：不得让读者以为 S(t) 在有限 t 处归零（曲线上限只画到画布边缘）
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— S(a)S(b) = 0.6065 × 0.3679 = 0.2231 = S(a+b) 与式 (8.1) 一致，λ = 1 已标注为示意。视觉 —— 第 1 轮恒等式文字压住区间括号，下移画布后第 2 轮通过。教学 —— 能回答「等待不改变剩余分布」；针对直观维度。

### 图 4 · fig-4-objmap
- 对应知识点：`c3` 分布（律）
- 打分：结构 2 / 过程 0 / 直观 1 / 辨析 1 = 4
- 依据：定义 8.2 一句话里出现 Ω、𝒜、ℙ、X、E、ℰ、ℙ_X 七个对象，读者说不清谁映射到谁
- 插入锚点：`c3-body` · 第 1 段之后
- 前置问题：ℙ 与 X 都已知，为什么还要造一个新测度 ℙ_X？
- 首要教学任务：让「分布 = 前推测度」的对象与映射关系变得可见
- 关键元素：左列概率空间、右列像空间与前推测度、两条带关系名的箭头、注记行
- 图后解释：X 把 ω 送到 E；ℙ_X(B) 取的是 X 落入 B 的原像在 ℙ 下的概率，即定义 8.2 那一行
- 理解检查：图 4 左侧为什么画了两块区域？（答案：X 可能把 Ω 的多个部分映进同一个 B，X⁻¹(B) 是它们的并集，所以原像不必与 B 同形。）
- 失败原因：以为「原像」与 B 是同一形状的两份拷贝。
- 图型与障碍类型：结构关系 → objmap()
- 图示规格：
  - 数学对象与符号：(Ω, 𝒜, ℙ)、(E, ℰ)、ℙ_X、映射 X —— 与定义 8.2 的记号一致
  - 对象之间的关系：X 是空间之间的映射；ℙ_X 是把 ℙ 沿 X 前推得到的测度
  - 阅读顺序：左框 → 上方箭头（X）→ 右框 → 下方箭头（前推）
  - 标识职责表：实线上方的关系名 X = 映射本身；下方箭头 = 由 ℙ 得到 ℙ_X 的操作；列标题 = 两个空间的角色（此刻区分「源」与「像」）
  - 与正文术语的对应：正文「前推」一词对应下方箭头的关系名
  - 不能暗示的错误结论：不得让读者以为 ℙ_X 作用在 Ω 上，或以为 X 是测度
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— ℙ_X 的定义域标为 ℰ、由 ℙ 与 X 共同决定，与定义 8.2 一致。视觉 —— 第 1 轮列标题压住对象框、单节点一侧不居中；标题下移并改为左右各自居中后第 2 轮通过。教学 —— 能回答「新测度解决的是换空间后怎么算概率」；针对结构维度。

### 图 5 · fig-5-chord
- 对应知识点：`e2` Bertrand 悖论
- 打分：结构 2 / 过程 1 / 直观 2 / 辨析 2 = 7
- 依据：读者会算出三个答案，但看不出「随机地取一条弦」这句话没有精确含义——分歧不在计算而在随机对象
- 插入锚点：`e2-body` · 第 1 段之后
- 前置问题：换一种「随机」，同一个事件还是同一件事吗？
- 首要教学任务：让三种「随机」各自对应哪块几何区域变得可见
- 关键元素：三个圆、内接等边三角形、临界弦（虚线）、长弦与短弦对照、三块允许区域（120° 弧 / 半径半段 / 内圆）、三行结果
- 图后解释：三格虚线都是弦长为 √3R 的临界弦；随机对象分别是端点、弦心距、弦中点，分母分别是弧长、长度、面积，于是 1/3、1/2、1/4
- 理解检查：三格里的「长弦」判据是同一个吗？（答案：是 —— 都是弦心距 &lt; R/2；不同的是随机对象，所以分母分别是弧长、长度、面积。）
- 失败原因：以为三种模型用了三个不同的判据，于是把「分母不同」误读成「条件不同」。
- 图型与障碍类型：几何直觉 → chord_models()（gcircle / garc / gchord / gpoly / ghline）
- 图示规格：
  - 数学对象与符号：圆半径 R、内接等边三角形边长 √3R、弦、弦心距 d、弦中点 M，与正文 §8.1.4 一致
  - 对象之间的关系：同一个事件「弦长 > √3R」在三种随机化下对应三块区域；三者都等价于弦心距 < R/2
  - 阅读顺序：左 → 中 → 右；每格内先看随机对象（点 / 段 / 区域），再看两条弦的长度对比
  - 标识职责表：橙色实线 = 长弦样本（读者要比较的对象）；灰虚线 = 短弦样本；橙色虚横线 = 临界弦（阈值本身，不是操作）；橙色弧 / 橙段 / 内圆 = 允许区域，即各自的分母；编号 ① ② ③ = 阅读顺序
  - 与正文术语的对应：正文「端点随机 / 弦心随机 / 中点随机」三处分别点名三格
  - 不能暗示的错误结论：不得让读者以为三格画的是同一族随机变量，或以为内圆是「圆内均匀」以外的分布
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— 临界弦长 = 2√(R²−(R/2)²) = √3R，与内接等边三角形边长一致；三格概率 1/3、1/2、1/4 与材料一致；三格的条件统一写成弦心距 < R/2。视觉 —— 第 1 轮只画了区域没画弦，读者看不到因果（结构完整但无教学价值）；补上长弦与短弦对照后第 2 轮通过。教学 —— 能回答「分歧来自随机对象不同，分母不同」；这是 e2 的关键想法，替代了原先只能读尾概率的数轴图。

### 图 6 · fig-6-package
- 对应知识点：`c5` 分布函数
- 打分：结构 1 / 过程 0 / 直观 1 / 辨析 2 = 4
- 依据：分布（律）与分布函数承载同一信息，读者分不清两者的分工与转换成本
- 插入锚点：`c5-body` · 第 2 段之后
- 前置问题：说的是同一个东西，为什么两个都要？
- 首要教学任务：把「同一信息、两种包装」的差别落到四行可比条目
- 关键元素：左右两栏同构画法、四行对照（定义域 / 能算的量 / 定义方式 / 原子可见性）、差异行强调框
- 图后解释：定义域一在 ℰ 上一在 ℝ；能算的量一针对事件一针对半直线；差异行说明 F_X 的跳跃点直接暴露原子
- 理解检查：只给 F_X 的图像，能否判断 ℙ_X 有没有原子？反过来呢？（答案：能 —— F_X 的跳跃点就是原子；而只给 ℙ_X 时必须逐个集合检验。）
- 失败原因：把「能算每个集合的概率」等同于「原子一眼可见」。
- 图型与障碍类型：对照反例 → compare()
- 图示规格：
  - 数学对象与符号：ℙ_X 与 F_X，定义域 ℰ 与 ℝ，与 §8.1.2、§8.1.6 的记号一致
  - 对象之间的关系：两者互相决定；F_X(t) = ℙ_X((−∞, t]) 是唯一转换式
  - 阅读顺序：逐行从上到下，左右同排对比；最后一行是差异焦点

### 图 7 · fig-7-marginals
- 对应知识点：`p2` 以为边缘分布决定联合分布
- 打分：结构 2 / 过程 0 / 直观 1 / 辨析 2 = 5
- 依据：读者知道「边缘是联合的积分」，但反过来的问题（边缘能否定出联合）只有看见两个不同的联合共享同一组边缘才会相信
- 插入锚点：`p2-body` · 第 1 段之后
- 前置问题：知道每个变量各自的分布，能不能还原它们的联合分布？
- 首要教学任务：让「边缘相同、联合不同」变成可见的差异
- 关键元素：两格同尺度方格、左格散点云、右格对角线上的散点、两格下方灰阶框内相同的边缘曲线、中间「完全相同」标注、两行联合结论
- 图后解释：两格边缘曲线相同（同一个 q），但左格是乘积密度 q(x₁)·q(x₂)，右格集中在对角线 x₁ = x₂ 上
- 理解检查：只看两格下方的边缘曲线，能区分哪一格独立、哪一格退化吗？（答案：不能 —— 两格边缘完全相同，这正是「边缘决定不了联合」。）
- 失败原因：试图从边缘形状反推联合结构，即这一卡要纠正的错法。
- 图型与障碍类型：对照反例 → marginal_joint_pair()
- 图示规格：
  - 数学对象与符号：(X₁, X₂) 与 (X₁, X₁)；边缘 ℙ_X₁ = ℙ_X₂ = q —— 与命题 8.6 之后的注一致
  - 对象之间的关系：两格共享同一组边缘；联合分别是乘积测度与对角线支撑
  - 阅读顺序：左格 → 右格（比较内部结构）→ 两格下方灰阶框内的边缘曲线 → 中间「完全相同」
  - 标识职责表：灰阶框 = 此刻要对比的部分（两处相同）；散点点阵 = 联合的支撑形状（示意）；虚线对角线 = 退化支撑的位置；「完全相同」= 结论标注
  - 与正文术语的对应：正文「除至多一个之外全是 Dirac 测度」对应右格的对角线支撑
  - 不能暗示的错误结论：点阵是示意，不能读成「q 就是正态」，也不能让读者以为两格的 q 不同
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— 两格边缘同为 q，联合一为乘积、一为对角线支撑，与命题 8.6 之后的注一致；右格 (X₁, X₁) 的支撑是直线 x₁ = x₂。视觉 —— 第 1 轮对角线方向画反（屏幕 y 向下使 y = x 呈左上→右下）；改为 y 轴向上并补 x₁ / x₂ 轴标后第 2 轮通过。教学 —— 能回答「边缘是联合的投影，投影相同不蕴含原对象相同」；这是 p2 的关键反例。

### 图 11 · fig-11-cdf-jumps
- 对应知识点：`c5` 分布函数 F_X（图 6 之后的补充）
- 打分：结构 2 / 过程 0 / 直观 1 / 辨析 2 = 5
- 依据：图 6 只写出「跳跃点就是原子」这条对照，读者仍需要一条具体的阶梯曲线，才能把「位置 ↔ 原子」「高度 ↔ 质量」对上
- 插入锚点：`c5-body` · 图 6 之后
- 前置问题：跳跃的位置给出原子在哪，那么跳跃的高度给出什么？
- 首要教学任务：让「跳跃高度 = 原子质量」在一条具体曲线上可读
- 关键元素：阶梯曲线、三处跳跃竖线、左极限空心圆、右极限实心圆、三个高度数值 0.2 / 0.3 / 0.5、轴标 F(t) 与 t
- 图后解释：三处跳跃高度之和为 1，正是三个原子的质量；两跳之间曲线平直，说明那些区间没有原子
- 理解检查：高度为 0.5 的跳跃对应哪个原子？（答案：t = 2 处的原子，质量 0.5）
- 失败原因：把跳跃的横坐标（原子位置）与高度（原子质量）混为一谈。
- 图型与障碍类型：对照反例 → cdf_jumps()
- 图示规格：
  - 数学对象与符号：F(t)、原子 (t_k, p_k) —— 与 §8.1.6 一致
  - 对象之间的关系：每个原子对应一次跳跃，跳跃高度等于该原子质量；水平段对应无原子区间
  - 阅读顺序：沿 t 轴从左到右；每次跳跃先看空心圆（左极限）再看实心圆（右极限），最后读高度数字
  - 标识职责表：橙色竖线 = 跳跃本身（此刻要读的量）；空心圆 = 左极限 F(t−)；实心圆 = 右极限 F(t)（已含原子质量）；高度数字 = 原子质量
  - 与正文术语的对应：正文的「跳跃点」「原子质量」分别对应竖线与高度数字
  - 不能暗示的错误结论：阶梯不能画成连续曲线；空心 / 实心的区别不能省略，否则看不出右连续
- 来源：生成（figlib）
- 状态：已内联
- 三层验收：数学 —— 跳跃 0.2 / 0.3 / 0.5 之和为 1，位置与质量与命题一致；实心圆取右极限符合 CDF 右连续的定义。视觉 —— 渲染后核对：空心圆在下、实心圆在上，高度标注未与曲线或轴标重叠。教学 —— 能回答「跳跃高度给出质量」，补上了图 6 只给对照、不给实例的缺口。
