## 二、十条可迁移手法

### 1. 同尺度并置（最强的一条）

多个变体、正例反例、左右对照并排时，**节点坐标必须完全相同**，只变高亮或映射。

- 证据：图 6.6（三张 Cayley 图坐标全同，只有绿色位置不同）、图 6.9（两张 3×3 网格坐标全同）、图 8.5（四行的域 / 余域图坐标全同）。
- 落地：把坐标写成一份数据，多个面板共享；**禁止各面板各自缩放或各自布局**——那样差异会被布局噪声淹没。
- 反例：左图横排、右图纵排，读者以为差别很大，其实只差一个条件。

### 2. 两条通道分离：色相给语义，灰阶给强调

| 通道 | 承载什么 | 令牌 |
|---|---|---|
| **色相** | 语义**种类**（生成元 1/2/3、类别 A/B/C） | `--gen-1..3` 或类别色 |
| **灰阶 / 光晕 / 填充** | 「此刻在强调什么」（子集、陪集、当前对象） | `--hl-1..n` |

- 证据：VGT 第 8 章把第 6 章的绿色高亮改成**灰色光晕**（图 8.12、8.17），因为第 6 章绿色既当生成元又当高亮，出现了冲突（该报告第 3.3 节把它列为跨章令牌统一的依据）。
- **可迁移结论**：当「强调通道」与「语义通道」可能同色时，**用灰阶 / 光晕承载强调，色相留给语义种类**。
- 落地：强调只改**节点的填充与描边**，不改边（边的颜色属于语义通道）。

### 3. 少数派原则：强调区 ≤ 全体一半

证据：图 6.3 的 3/6、2/6、4/8，图 6.7 的 2/6，图 6.9 的 3/9 —— 高亮区**永远是少数派**，保证视觉焦点唯一。

- 落地：若需要强调的部分超过一半，改成「强调其余部分」或换一种表达（读者会失去焦点）。
- 附带做法：提供**高亮开关**，让读者先自己找，再显示答案（原书的 "Take a moment to spot..."）。

### 4. 结果用填充，过程用箭头

证据：图 6.9 的两张图里，**节点填充**表示「算出来是哪个集合」，**粗箭头**表示「沿着哪条路算过去」。两者分工明确，读者能同时看到过程与结果。

- 反例：把过程路径也涂成高亮色，读者分不清哪是中间态、哪是结论。

### 5. 反例矩阵：每行同构，只变一处

证据：图 8.5 四行 = 四种「不是同态」的症状（漏元素 / 一对多 / 不保运算 / 不保单位元），每行的域图、余域图、映射形态、右侧理由位置**完全一致**。

- 落地：反例卡的固定结构 = 域图 / 映射 / 余域图 / 一行理由；**理由默认折叠**，让读者先自己判断。
- 与「判定类知识必配正反例」配套：判定题的图要成对出现，正例与反例用同一套画法。

### 6. 抽象骨架 + 具体实例成对

证据：图 8.13（3 个圆：G、G/Ker(φ)、Im(φ)）→ 图 8.14（A₄ 的完整实例），图 8.20（参数化网格）→ 图 8.19（C₃×C₄ 实例）。

- 落地：**骨架图先立结构（3 对象 3 关系就够），实例图紧接其后**，两者命名严格对应（G ↔ A₄、Ker(φ) ↔ {e,x,y,z}）；不要把实例图放到另一屏或另一张卡。
- 本 skill 用法：`proof()` 画骨架，`objmap()` 或几何图型画实例，两张图的图注互相点名。

### 7. 映射用点状虚线，关系多于 6 条时改配对照表

证据：图 8.1–8.9、8.19、8.23 全用点状虚线表示函数对应；图 8.9 右侧配 `x ↦ y` 的显式列表，让读者**绕开密集线条直接读表**。

- 落地：对应关系 > 6 条时，同时给出表格视图；线太密就折叠成表。

### 8. 分阶段图：每格一个变化 + 格下文字标签

证据：图 8.12（原结构 → 陪集拢近 → 塌缩）、图 8.24（三步，标签写明每步产出）。

- 落地：每格只引入**一个**视觉变化；格下写一句阶段标签（不是编号，是**这一步在做什么**）；前一步的元素保留但降权。

### 9. 无限对象截断 + 省略号，且编号保持可见

证据：图 8.15（ℤ 的 −3…3）、8.16（两段）、8.17（卷成环）。

- 落地：**不要尝试渲染无限节点**；画有限窗口 + 省略号，并让节点标签完整可读。

### 10. 图内写短语标签，图注只写「子图之间的关系」

证据：图 8.18 图内的 "The homomorphism φ gives the remainder..."、图 8.24 的三阶段标签、图 8.11 的 "ambiguous blue arrows"；图 6.12 的图注只说明「三张图是同一件事的不同布局」。

- 落地：解释性的短句**写在图上**（靠近它解释的元素）；图注只保留一句「这些面板之间是什么关系」+ 正文出处。
- 反面：图注写成一段长解释，正文再重复一遍。

### 关于复分析：它带来的法则怎么取舍

复分析·可视化方法**不再作为参考来源**——作者本人也注意到该书配图偏严谨、直观性不足。但它已经贡献过几条规则，按最初约定的取舍标准（图要解决理解问题、服务六类障碍、服从位置与闭环要求）逐条处理：

| 它带来的 | 取舍 | 理由 |
|---|---|---|
| 图宽 46–69% 版心，从不整页铺图 | **丢弃** | 那是印刷版心的约束；我们的载体是宽屏 HTML，已定为出栏（方案 A） |
| 全章零彩色、语义靠灰度 3 级 | **丢弃** | 印刷限制而非设计优点；我们的页面走双主题令牌，色相要承载语义 |
| 图注只有编号、解释权全归正文 | **降级为不用** | 与「图文闭环」冲突——图注要给一句话，正文才展开 |
| 多面板 + 逐面板引用（图 1-6a 表明…） | **保留** | 服务「过程理解」障碍，且与 VGT 的做法互补 |
| 局部放大 + 虚线引导（无穷小论证） | **保留** | 服务「直观理解」障碍，PDF 与 HTML 都需要 |
| 术语表 + 一张解剖图（替身手段） | **保留** | 是「重要但不配图」的合法替身 |
| 图前 1–3 句、图后 1–4 句、每 8 张一次任务句 | **保留** | 与 VGT 实测一致，是位置与闭环的量化依据 |

**结论**：复分析的贡献是**通用手法**（多面板、局部放大、篇幅量化），丢弃的是**印刷约束**（版心宽度、零彩色、纯编号图注）。

**复杂度结论**：对象数 **12–14** 在 VGT 三章稳定；**关系数上限按图型浮动**（对照 / 结构类 ≤8，网络 / Cayley 类可达 12–24），复分析的 14/8 只作旁证。

因此本 skill 的分档：

| 类型 | 对象 | 关系 |
|---|---|---|
| 结构关系图 / 对照反例图 / 证明流程图 | ≤14 | ≤8 |
| 几何直觉图 | ≤14 | ≤8 |
| 网络 / 依赖类（`depgraph`） | ≤14 | ≤16（超过则重排或拆视觉独立部分） |
| 数据分布图 | 按数据点数，不设对象上限 | 横档 / 柱的数量不计入关系 |
