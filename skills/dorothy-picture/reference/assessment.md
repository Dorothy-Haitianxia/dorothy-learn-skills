# 制图评估：打分表、六问闸门与图型选择

本文件回答三件事：**值不值得画**（第二节）、**画之前必须回答什么**（第三节）、**该画哪一类**（第五节）。

## 一、评估三步

1. **提取知识点**：概念、定义、定理、证明、例题、易混点、知识关联。
2. **识别理解障碍**：明确读者可能在哪里误解、卡住、无法继续推理。
3. **打分**：用第二节的四维表给出 0–2 分，并写下打分依据。

**重要知识点 ≠ 必须配图；但所有重要知识点都必须经过评估。**

## 二、配图决策打分表

对每个重要知识点，四维各打 0–2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **结构理解困难** | 对象与关系在文字里一目了然 | 对象多，但列表或编号能排清楚 | 说不清有哪些对象、谁包含谁、谁映射到谁；**必须看见结构才能继续** |
| **过程理解困难** | 没有过程，或过程只有一步 | 步骤多，但按序号列出来就能跟上 | 知道起点终点，却不清楚中间发生了什么、每一步为何如此 |
| **直观理解困难** | 纯符号操作，不需要空间直觉 | 有几何含义，但公式已经够用 | 抽象定义转不成空间直觉；**非看见图形不可** |
| **关系辨析困难** | 没有易混对象 | 有易混概念，但对照表能说清 | 两个概念只差一个条件，或需要正反例并置才分得清 |

### 分数怎么用

| 总分 | 处置 |
|---|---|
| **任一维 = 2，或总分 ≥ 4** | **高优先级：必评，且优先制图** |
| 总分 2–3 | 交给第三节的六问决定；六问答不全就不画 |
| 总分 0–1 | **不出图**；分数本身就是理由（仍要在清单里写一行） |

### 两条加权（基于阅读体验，2026-10 补充）

打完四维分之后，按下面两条**加权**，再决定优先级：

| 加权项 | 加多少 | 依据 |
|---|---|---|
| **例题卡（EX）** —— 课本里的典型例子 | **+1** | 例子是直观体验的关键所在：二项分布、高斯分布这类典型例子处，一张函数图像比定义里的公式更早建立直觉 |
| **被本章多张卡依赖的概念** | **+1** | 被依赖度高的概念一旦没讲透，后面每张卡的困难都会放大；被 ≥3 张卡引用即算 |

被依赖度可以直接从互引数据里数（dorothy-html 的 `refs.py` 会给出每张卡被引用的次数）；例题卡则按卡片语义标签（EX）识别。

加权后的分数用在同一条阈值上：**任一维 = 2 或总分 ≥ 4 → 必评并优先制图**。

**典型效果**：ch08 的 e4（Poisson 的二项逼近）原本 4 分、e2（Bertrand）8 分，加权后 e4 升到 5 分，与它在页面里的作用相称；而 c3（分布，被 6 张卡引用）从 4 分升到 5 分，进入优先队列。

两条纪律：

- **打分必须附依据**：写清是「哪句话 / 哪一步 / 哪两个概念」让读者卡住，不许只填数字。
- **分数决定审查优先级，不是学习效果预测**。不因为总分高就硬画，也不因为总分低就跳过评估。

## 三、六问闸门（答不全就不制图）

每个候选图必须逐条回答：

| # | 问题 | 答不出来的后果 |
|---|---|---|
| 1 | 读者**具体**会在哪里遇到困难？ | 还没定位障碍 → 回到第一步 |
| 2 | 图需要让读者看见**什么关系或变化**？ | 图没有任务 → 不画 |
| 3 | **为什么图比纯文字、公式或对照表更合适？** | 表达方式选错了 → 改用表格 / 公式 / 编号回指 |
| 4 | **如果删除这张图，读者会失去什么？** | 答不出会失去什么 → **这张图是装饰，删掉** |
| 5 | 读者看完图后应当能**解释什么**？ | 无法验收 → 先定验收问题 |
| 6 | 这张图**不能暗示哪些错误结论**？ | 有误导风险 → 不画，或先在图上堵住 |

第 4 问与第 6 问是最强的两道闸门：前者拦装饰，后者拦误导。

## 四、必配图 / 通常不配图 / 替身手段

下面三条来自两本配图优秀的教材实测（复分析·可视化方法第 1 章 34 张图、Visual Group Theory 第 2 章 10 张图），可直接当先验：

### 几乎必配图

| 类型 | 为什么 |
|---|---|
| **空间动作与其实施结果**（变换、翻折、复合、构造） | 动作本身在文字里不可见，必须「动作 + 结果」成对图示 |
| **几何构造与作图** | 凡「在平面上作出某个点 / 线」的内容，一律配图 |
| **状态的集合与可达关系**（地图类） | 关系网用图才有意义，文字列边等于自找麻烦 |
| **同一表达式的两种读法**（符号 ↔ 几何） | 公式图解的固定角色 |
| **易混概念的两类事物** | **必配对照图，且用填充样式与线型区分**，不靠文字解释 |
| **同构的不同载体** | 复用同一套布局坐标，只换渲染皮肤，比文字说明省力 |
| **抽象化前后对照** | 抽象动作本身要配图，并逐句说明替换了什么 |
| **无穷小 / 极限的几何论证** | 需要「局部放大 + 虚线引导」 |
| **判定类知识**（「它是否满足定义」） | **正例与反例必须成对出现**，且用同一套画法；反例要给出可见症状（教材：VGT 图 6.6、8.5） |
| **定理的一般式** | **抽象骨架图 + 具体实例图成对**，命名严格对应；骨架 3 对象 3 关系就够（教材：VGT 图 8.13 → 8.14） |
| **对象之间的对应关系** | 统一形态的引导线（点状虚线）+ **显式对照表**；关系多于 6 条时以表为主、线可折叠（教材：VGT 图 8.9） |
| **无限对象** | 有限片段 + 省略号，**节点编号必须保持可见**；不要尝试渲染无限节点（教材：VGT 图 8.15–8.17） |
| **同一内容的多种表征** | 每种表征各画一次并点明差别（教材：VGT 图 8.2/8.4 → 8.6 → 8.7） |

### 通常不配图

- **纯代数推导**（分式分解、因式定理、配方展开）；
- **历史与背景叙述**；
- **习题的纯文字部分**；
- **术语列举**——改用「表格 + 一张解剖图」配对，而不是每个术语一张图。

### 重要但不配图时的替身手段

| 手段 | 出处 | 适用 |
|---|---|---|
| **结构化编号排版 + 编号回指** | VGT 的 Observation 1.1–1.4 / Rule 1.5–1.8 被反复引用却从不配图 | 有稳定编号的规则、定义、约定 |
| **术语表 + 一张解剖图** | 复分析书页 5 的 10 条术语表 + 图 1-4 | 一批术语需要一次性交代位置与记号 |
| **排版公式** | 复分析三次方程求根 | 符号推导本身 |
| **缺失的连接** | VGT 图 2.6 用缺一条边表达地图还不完整 | 要让读者自己发现缺口的内容 |
| **纯文字推导 + 与已知规则逐项对比** | 复分析空间复数与四元数一节 | 新对象可由旧法则逐项平移得到 |

**这些替身必须写进清单**，不能只写「不出图」。

## 五、图片类型 → 图型

制图之前先明确**类型**，再选具体图型。五类：

| 类型 | 何时用 | 图型入口 |
|---|---|---|
| **结构图 / 关系图** | 对象、包含、映射、依赖、状态与可达 | `objmap()` `depgraph()` `stages()` |
| **几何直觉图** | 空间、覆盖、距离、区域、构造、变换 | `gcircle()` `garc()` `gchord()` `gpoly()` `ghline()`，参考实现 `chord_models()` |
| **证明流程图** | 关键推理步骤、某一步为何成立、用了什么工具 | `proof()` |
| **对照图 / 反例图** | 易混概念、边界条件、正反例、两种读法 | `compare()` `axis()` |
| **数据分布图** | **仅当材料本身给的就是分布 / 计数 / 逼近** | `bars()` `line()` `area()`（参考实现，见 `figlib.py`） |

选型的三个前置判断：

1. **这张图要消解哪一维困难？**（结构 / 过程 / 直观 / 辨析）—— 维度决定类型。
2. **材料本身是结构还是数据？** 是数据才用分布图；结构一律用结构图或几何图。
3. **一张图能承担几个任务？** 可承担多个辅助任务，但**必须有一个主要任务**；主要任务超过一个就拆图。

## 六、评估强度

| 强度 | 规则 | 何时用 |
|---|---|---|
| **全量** | 六类内容源逐条评估，一条不漏 | 默认；章节规模 ≤40 个知识点 |
| **抽样** | 定义与例题**必评**；定理与习题按是否含转折 / 构造 / 反例抽评 | 章节过大（>40）且全量会拖垮篇幅 |

抽样时必须写明**抽样规则与未评条目**，不许默默跳过。

## 七、结论模板句

出图：

```
## C3 分布（律）  → 出图
- 打分：结构 2 / 过程 0 / 直观 1 / 辨析 1 = 4
- 依据：定义 8.2 同时出现 Ω、𝒜、ℙ、X、E、ℰ、ℙ_X 七个对象，读者说不清谁映射到谁
- 类型：结构图 / 关系图 → objmap()
- 首要教学任务：让「分布 = 前推测度」的对象与映射关系变得可见
```

不出图：

```
## T5 方差计算公式  → 不出图
- 打分：结构 0 / 过程 0 / 直观 0 / 辨析 1 = 1
- 理由：𝔼[(X−a)²] = var(X) + (𝔼[X]−a)² 是纯符号配方，每一步都在正文展开
- 替身：结构化排版（配方 + 一行说明）
```
