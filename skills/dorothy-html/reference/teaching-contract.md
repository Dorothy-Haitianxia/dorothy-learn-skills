# 教学稿契约

> 本文件是**从 ch08 试点反推**出来的，不是先设计再落地。凡是与试点不一致的地方，以试点为准并回头改本文件。
> 试点规模：30 单元 / 51 处增补 / 33 张卡全覆盖（试点材料含教材衍生内容，只本地留存，不随仓库分发）。

## 一、三层分工

一份笔记由三层拼成，**不能混在一起写**：

| 层 | 内容 | 谁写 | 落盘位置 |
|---|---|---|---|
| 第一层 教材转述 | 原文的忠实译文，逐句可对回原书 | 翻译流程 | `<教材译文>.html` |
| 第二层 **教学稿** | 按理解顺序重排 + 直觉 + 回放 + 检查 | 本契约约束 | `<产物>_teaching.md` |
| 第三层 HTML | 卡片、板块、地图、主题 | `dorothy-html` | `<产物>.html` |

**关键纪律**：教学稿是**文本**，不是 HTML。它的消费者是"要把文字塞进卡片的人"和"要审内容的人"，两者都不该读标签。

## 二、读者档位

教学稿开头必须声明档位（默认 **A+**）。档位改变的是**增补密度**，不改变内容正确性：

| 档位 | 对象 | 直觉类增补 | 前置回放门槛 | 每单元正文 |
|---|---|---|---|---|
| **A** 零基础 | 没学过 | 每单元必给 | 全部前置都回放 | 最长 |
| **A+ 遗忘型（默认）** | 学过、忘得差不多 | 抽象概念必给 | N ≥ 3 才回放（见下） | 中 |
| **B** 讲义 | 正在上课 | 只给难点 | 只给跨课程前置 | 中 |
| **C** 速查 | 复习 | 不给 | 不给 | 最短 |

试点选了 A+：它在 30 单元里触发 51 处增补，其中 15 处是直觉、15 处是最小例子——**这两个比例是 A+ 的特征**，A 档会显著更高，C 档接近 0。

## 三、前置概念的 N 规则

**N = 该前置概念在本章正文被使用的段落数**（段落以空行分隔；标题、摘要行、出处行不计）。

| N | 处置 |
|---|---|
| ≥ 3 | 必须给**回放**：一句话定义 + 一个最小例子，标 `.is-recall`（HTML 里可折叠） |
| 1–2 | 只给**术语回指**（"见 A2"，不解释） |
| 0 | 不统计 |

两条补丁，缺一就会漏：

1. **关键位置豁免**——出现在本章的定理陈述、定义的前提条件、证明的关键步骤里的前置概念，**N = 1 也按 N ≥ 3 处理**。理由：在关键节点只给回指，等于没给。试点触发 3 次（单调收敛、简单函数、Stone–Weierstrass）。
2. **跨课程按 A 档**——概率论用到的微积分、线性代数、测度论一律完整解释，**不受 N 约束**。理由：读者对这些的遗忘是彻底的，N 再高也说明不了"他还会"。

**实测代价**（ch08）：199 个正文段落 → 19 块回放 / 25 条前置概念（一条折叠区里可能并列 2–3 个概念）。首轮写出来是 21 条，其中 2 条被第四节的门槛删掉：`随机变量是函数`（本章第一张卡就是它）、`Poisson 分布`（《经典分布清单》卡里有定义）——**本章自带落点的概念不该占用回放**。这条数据很重要：**N 规则不是"给所有前置都回放"**，它筛掉了约 80% 的前置。

统计脚本：`.work/count_n.py`（按章节复用需改关键词表）。N 值表写进教学稿的「章首诊断」节，一行一个概念。

## 四、单元粒度

**一个单元 ≠ 一张卡**。试点 33 张卡压成 30 个单元。

| 情形 | 处置 | 试点实例 |
|---|---|---|
| 两张卡的**理解障碍是同一个**（一个是另一个的直接推论） | 合并成一个单元 | t5（方差公式）+ t6（两个不等式）都靠"配方"；t3（边缘公式）+ p2（边缘不决定联合）是同一件事的两面；e2（Bertrand）+ p1（随机取弦无含义）本来就是一句话 |
| 一张卡的证明或计算**能独立成篇** | 单独成单元（不合并进主体） | e5（高斯特征函数的计算） |
| 易错点卡的障碍与某张概念卡相同 | 不单独成单元，挂在概念卡的「易错」小节 | p3 挂在 F4 但主体是 c5 的"密度值"注 |

**判据**：合并的单元里，"学习问题"必须能写成**一句**话。写不成一句，说明该拆。

## 五、内容来源的五分类

每一段正文必须能归入下面前五类之一，且除①②③之外的都要打标记：

| 类 | 含义 | 标记 |
|---|---|---|
| ① 原文 | 教材句子的直接转述，逐句可对回 | 无标记 |
| ② 重排 | 原文内容不变，位置或顺序变了 | 无标记（重排本身在 0.3 节声明） |
| ③ 补步 | 教材跳过但属于"标准技巧"的中间步骤 | 无标记，但必须在「来源」里写清补的是哪一步 |
| ④ 增补-直觉 | 比喻、模型、可想象的对应物、判据 | `[增补]` / HTML `.is-added` |
| ⑤ 增补-例 | 最小可验算的例子、反例、边界情形说明 | `[增补]` / HTML `.is-added` |

**③ 与 ④⑤ 的界线**：③ 是"读者自己能推出来，只是教材懒得写"；④⑤ 是"读者推不出来，因为教材没提供这个视角"。**这条界线决定要不要打标记**——打了标记，读者就知道"这句不是原书说的"，可以怀疑。

HTML 侧（**已实现**）：`.is-added` 是一条段级极浅左线（正文不放任何字样标记，也不做折叠、不做文末清单）；`.is-recall` 用 `<details>` 折叠，标题写「回放 · N 处：<概念名>」。模板骨架与 `scripts/inject_teaching.py` 都按这个结构产出。

## 六、每单元的字段

### 必需（6 项，缺一项就不算单元）

| 字段 | 写法要求 | 试点反例 |
|---|---|---|
| **学习问题** | 一句话，以问号结尾，且**必须是读者真的会问的** | ✗ "理解分布函数的定义" → ✓ "为什么 ℙ_X 是集函数而 F_X 是普通函数？" |
| **正式** | 引 §号或命题号；公式与教材一致，不加自己的记号 | 无 |
| **检查** | 一个问题 + **答案**（必须在同一行给出） | 无 |
| **图示任务** | 要么给图号，要么给**不出图的四维分数与理由** | ✗ "此处配图更清晰" → ✓ "不出图（1/1/0/0 = 2）。理由：与 C6 的投影图重复" |
| **前置回放** | **条件必需**（字段必写，内容看条件）：先过第三节的 N 门槛，再过这一条——只回放本章**没有卡片**的前提（跨课程工具、前几章结论），写法"概念（N = ?）：定义 + 最小例子"；本章已有卡、浮层与知识地图都能跳的，写"无新增" | ✗ 留空；✗ 复述本章已有的卡（例：某卡就在讲"随机变量是函数"时再回放它，折叠区会变成每张卡都有的例行公事） |
| **来源** | §号，或"教材原易错点 p_ ×" | 无 |

### 条件（有则必写，无则省略）

| 字段 | 触发条件 |
|---|---|
| **直觉** | 该卡是定义型或定理型（EXAMPLE 卡可省） |
| **易错或技术点** | 该卡在 `figures-plan` 的辨析维度 ≥ 1，或对应某张 p 卡 |
| **图前引导 / 图后解释** | 该单元对应 `figures-plan` 里的**出图**条目（否则不写——这是与 dorothy-picture 的分工边界） |

### 可选

**技术备注**（如"渲染器差异"、"教材记号不一致"）。可选字段全章应 ≤ 5 处，否则说明在堆信息。

## 七、与 dorothy-picture 的分工

**不重复**：图示的 11 字段决策卡（对应知识点 / 打分 / 理解障碍 / 教学任务 / 插入位置 / 编排 / 视觉顺序 / 图文对应 / 图后解释 / 理解检查 / 替代文本）住在 `<产物>_figures-plan.md`，字段口径见 dorothy-picture 的 `reference/plan-contract.md`。

教学稿只写两样：

1. **图前引导**（1–3 句）：告诉读者"先看什么"。
2. **图后解释**（1–4 句）：告诉读者"刚才看到的是什么"。

两者都是**正文**，会被 `dorothy-html` 内联到图的前后。**判据**：把图从页面里拿掉，这两段应该读不通——读得通说明它们在讲自己的事，不是在图前/图后。

## 八、修改纪律（本轮生效）

1. 新增文档 ≤ 3 份（本轮：教学稿 + 本契约 + 校验器，校验器不计入文档）。
2. 新增必填字段 ≤ 6（本轮：6 项，正好用满，**下一轮不许再加**）。
3. 每条新增必须说明**替代了什么**：直觉替代"让读者自己猜为什么"；回放替代"回翻前一章"；检查替代"读完以为会了"。

## 九、校验器约定

`python scripts/check_teaching.py <教学稿> [--html <页面>] [--plan <清单>]`

| 检查 | 判定 |
|---|---|
| 档位声明 | 头部必须出现 A / A+ / B / C 之一 |
| 六簇结构 | 至少 2 个 `## 簇` 标题（允许自定义簇名，不允许没有分簇） |
| 必需字段 | 每个 `### ` 单元下必须出现 6 个必需字段名（「前置回放」写"无新增"也算出现；**内容**要求见第四节那行：只写本章没有卡的前提） |
| 检查带答案 | 每个「**检查**」段落必须含「**答案**」 |
| 图示任务二选一 | 含「出图」或含「不出图」（且不出图必须带分数与理由） |
| 增补清单完备 | 正文 `[增补]` 计数 == 附表行数 |
| 禁用词 | 不含"更清晰 / 更美观 / 更直观 / 更易懂" |
| 卡片对账（`--html`） | 单元标题里的 `(cN/tN/eN/pN)` 必须在页面里有对应 `id`；反之页面里的卡必须有单元覆盖 |
| 出图对账（`--plan`） | 教学稿标"出图"的单元必须出现在清单的出图名单里 |
| 教学层（`check_note.py` 第 13 组） | 学习问题 / 理解检查 / 答案折叠三者数目一致；有教学层必有 `.tk-src` 原文分隔；增补段只用 `.is-added` 段落左线区分（正文不写「补」小标、文末不做附录；若附录出现了则正文必须有对应增补段） |

## 十、教学层在 HTML 里的落位

教学稿的字段有固定去处，构建时按这张表注入（教学层自 0.3 起生效；**`assets/note-template.html` 已按这张表内建骨架与样式，新产物默认就带教学层**）：

| 教学稿字段 | HTML 位置 | 收起状态可见 |
|---|---|---|
| 学习问题 | 卡头 `.tk-q`：定义卡/例题卡挂在 `.card__summary` 之后，定理卡挂在 `.card__head` 之后 | 是 |
| 直觉 | panel 内 `.tk-note`，第一块 | 否 |
| 前置回放 | panel 内 `<details class="is-recall">`，summary 写「回放 · N 处：术语…」 | 否（默认收起） |
| 教材原文 | `<div class="tk-src">` 包住原 panel 内容，前有小标「教材原文」 | 否 |
| 检查 | panel 内 `.fig__check tk-check` + 答案 `<details class="tk-ans">` | 否 |
| 增补段 | 段级 `.is-added`：一条极浅左线，正文里**不放**任何字样标记 | 否 |
| 附：我补了什么 | **不进读者页**（构建仍支持 `#p-added` 独立页，但默认不注入——读起来像附录报表，打断翻页） | — |

三条硬规则：

1. **收起状态必须先回答「这张卡为什么存在」**——所以只有学习问题上到卡头，其余留在 panel 里。
2. **教材原文必须被 `.tk-src` 框住**：读者要能一眼分出这段是书上的还是导师的。
3. **`[增补]` 逐段标记**：含增补的段落自己带 `.is-added`（段落级左线），不许整块容器一把糊住；**不写「补」字小标**（读者嫌碍眼），也**不在文末做「我补了什么」清单**（审计价值留给教学稿本身，读者页不背报表）。

**为什么不是把所有教学层都放卡外**：卡外只放一行学习问题，是为了让「要不要展开」成为读者的决定；把直觉和检查也放外面会让卡片区变成正文，缩略浏览失效。
