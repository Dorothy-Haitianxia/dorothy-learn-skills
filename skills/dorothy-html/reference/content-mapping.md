# 内容映射契约：输入 Markdown → 知识笔记 HTML（宽屏翻页版）

## 一、总原则

1. **只用输入材料里的话与事实**。可以压缩、可以换行排布，但不能引入材料没有的判断、例子、数字。
2. 材料缺的一律写 `[待补充]`，并写清缺的是什么。
3. 每张卡、每道自测题、每道课本章末习题都要有出处行（`card__src`）。
4. LaTeX 转写成可读的 Unicode/HTML：`$\mathbb{E}[X]$` → `𝔼[X]`、`X^{-1}` → `X<sup>−1</sup>`、多行 aligned 拆成若干 `.formula` 块。**不引入 KaTeX/MathJax**。

## 二、五页对应

| 页 | 取自输入 | 处理规则 |
|---|---|---|
| `#p-overview` | 章节标题与全文 | 章节名照抄；三个统计数按卡片统计；关键结论一行取正文 |
| `#p-map` | 正文小节结构与定义间依赖 | 分层：基本对象 → 分析工具 → 结论；关系只写材料明确写出的 |
| `#p-core` | 定义、定理、命题、引理、例题、经典对象 | 一个概念一张卡；证明跟所属定理走；命题/引理独立成定理卡；卡片按 `DEF`/`THM`/`EX` 归到**三个板块**（定义 / 定理 / 例子），板块卡数写进分段控件 `.tabs__n`，默认显示「定义」；该板块也是**顶栏全局搜索的唯一索引范围**（出处行不进索引）|
| `#p-pitfalls` | 正文“注 / 特殊情形 / 反例” | 每条能指回材料；没依据的不收 |
| `#p-quiz` | 正文关键陈述 + 课本章末习题 | **两块**：`#board-self`（自测，默认可见）+ `#board-exercise`（`hidden`，`data-tabs="quiz"` 的分段控件切）；自测：陈述改问句、答案照材料；习题：题目照抄课本，课本给了答案才做展开面板，没给写 `[待补充]` |

## 三、卡片槽位

概念卡：

```html
<article class="card" id="cN">
  <div class="card__head">
    <p class="tag"><span>DEF</span><span class="tag__cn">定义</span></p>
    <h3 class="card__title">概念名</h3>
  </div>
  <p class="card__summary">一句话摘要（扫读层）。</p>
  <button class="toggle" type="button" aria-expanded="false" aria-controls="cN-body"
          data-open-label="收起完整定义" data-close-label="展开完整定义">
    <span class="toggle__tx">展开完整定义</span><span class="toggle__ico" aria-hidden="true">+</span>
  </button>
  <div class="panel" id="cN-body" hidden>
    <div class="panel__inner prose">
      <p>完整定义（材料原文表述）。</p>
      <p class="formula">公式<span class="formula__no">定义 X.Y</span></p>
      <p class="card__src">出处：正文 §x.y</p>
    </div>
  </div>
</article>
```

**分板块**：`.stack[data-accordion="core-def"]` → `#board-def`（默认可见）、`core-thm` → `#board-thm`（`hidden`）、`core-ex` → `#board-ex`（`hidden`）；板块标签用「定义 / 定理 / 例子」，卡数写进对应 `.tabs__tab` 的 `.tabs__n`。板块内不再重复写小标题（分段控件就是子标题），**两块必须是兄弟，不能把一块的 `.stack` 塞进另一块里**。

定理卡把常显部分换成：

```html
<dl class="facts"><dt>条件</dt><dd>…</dd><dt>结论</dt><dd>…</dd></dl>
```

例题卡：`.card__summary` 写题目，展开写解答（`<ol>`）。易错点卡（`ERR`）：标题＝错误说法（照抄材料出现过的说法），摘要＝触发场景，展开＝限制条件 + 正确做法。自测题 `.quiz`：问题在 `.quiz__q`，答案面板 `id="qN-a"`，**不放进 `data-accordion` 组**。课本章末习题 `.quiz--ex`：题号写在 `.quiz__no`（如 `习题 8.5`），多小问用 `.quiz__part` 分行；**课本给了答案**才照自测题的写法出展开按钮，**没给**就用静态 `.quiz__ans`（`<span class="mono">答案</span><span class="wait">[待补充]</span>`）——"可展开的答案（若有）"的"若有"就落在这一句。

## 四、互引标记的取词规则

标记由 `scripts/refs.py` 做，你只需要拟好两张表：

**别名表 `ALIASES`**（目标卡, 术语, 正则或 None, 备注）。取词优先级与取舍：

1. **编号引用优先**：`定义 8.2`、`命题 8.5`、`引理 8.7`、`定理 8.16`——材料里本来就有，最精确。带数字的别名必须写成正则并加负向断言（`定义\s*8\.1(?!\d)`），否则会吞 `定义 8.12`。
2. **记号其次**：`𝔼[X]`、`var(X)`、`cov(X,Y)`、`F_X`、`Φ_X`、`L_X`、`σ(X)`。注意上下标在纯文本里会被并成 `FX`/`ΦX`/`LX`，所以别名要写并合形态；`σ(X)` 必须保留括号正则，否则会命中标准差记号 `σX`（那属于方差卡，不是 σ-域卡）。
3. **专有概念名再次**：`分布（律）`、`特征函数`、`Laplace 变换`、`Poisson 分布`、`边缘分布`、`Fourier 变换`、`无记忆性`…
4. **基础通用词不收录**：`随机变量`、`随机向量`、`期望`、`分布`、`方差`——每张卡都出现，标了没有信息增量。经验值：25–35 张卡的章节，标出 15–25 处。

**守卫表**：

- 左侧 `EXCLUDE`：`二项 / 几何 / 均匀 / 指数 / Gamma / Cauchy / 高斯 / 正态 / 边缘 / 条件 / 离散 / 连续 / 复合` + `分布`；`协` + `方差`；`条件 / 数学` + `期望`。
- 右侧 `SUFFIX_BLOCK`：`分布` + `函数 / 律 / 列 / 族`（这些属于别的卡或自身别名）。

工作流：写内容 → `refs.py --file …` 出审报告 → 逐条看「会标出的位置 / 同卡重复不标 / 被守卫拦下 / 其它章节编号引用」四节 → 确认后 `--apply`。

## 五、插图：图型由 dorothy-picture 提供

插图不在这一侧生成。**制图评估、图型选择、八字段规划、渲染核对都在 `dorothy-picture` 里做**（它的 `reference/assessment.md` 有六类障碍 → 图型对照表）。本侧只做三件事：

1. 产出 `<产物>_figure-assets.md`（本地可用图清单：路径 / 尺寸 / 能讲什么）；
2. 把 `figs/fig-<N>-<slug>.html` 插到规划清单写的**插入锚点**处，并写图前引导与图后解释；
3. 执行**来源优先级**：本地已有图库 > 生成图 > 占位图（比较在 dorothy-picture 侧做，本侧只落地）。

下面这张表是 dorothy-picture 图型库里**数据图型**的参考实现，用于核对数据来源：

| 结构 | 适用 | 数据来源示例 |
|---|---|---|
| B1 rung bars | 少类目概率/计数 | 二项 `C(n,k)p^k(1−p)^{n−k}` 与 Poisson 极限 `λ^k e^{−λ}/k!` 对照（n = 5/20/100，np = λ） |
| B2 hairline line | 一条曲线的形态与关键点 | 生存函数 `e^{−λt}` 与 (8.1) 无记忆性 |
| B3 hairline area | 两条曲线/面积即概率 | 两条密度 `p(x)=1/(π√(1−x²/4))` 与 `q(x)=x/2`，阈值 √3 之后的尾面积 1/3 与 1/4 |

写图注时把这三件事写进去：**可数单位**（`ONE RUNG = 1%`）、**示意参数**（“取 λ = 1 示意”）、**截断或发散**（“p 在 x → 2⁻ 处发散，曲线在 1.915 处出图”）。

## 六、数量与时长

| 元信息 | 算法 |
|---|---|
| 知识点 | 概念卡 + 定理卡 + 例题卡数（不含易错点与自测题） |
| 定义 · 定理 | `DEF` 卡数 / `THM` 卡数（命题、引理、不等式都算 `THM`） |
| 预计复习 | 知识点 × 1.5 min + 自测题 × 1 min，向上取整到 5 min |

## 七、文件名与放置

- `chXX-章节名.html`，`XX` 与材料章号一致。
- 放在该科目工作区；若科目有既有命名习惯，服从习惯并在翻页器来源行注明。
- 交付后跑 `scripts/check_note.py` 与 `scripts/refs.py`，再在浏览器里过一遍。

## 八、缺料时的写法

| 情况 | 写法 |
|---|---|
| 课本习题没有答案 | 静态 `.quiz__ans` 写 `[待补充] 课本只给题目、未给解答`，**不要**生成展开按钮 |
| 正文里没有“注/反例” | 易错点区只收有材料依据的条目；翻页器来源行只写正文 |
| 定理只给结论没给条件 | `facts` 的条件写 `[待补充]` |
| 证明被材料跳过 | 展开里写思路并标注哪一步 `[待补充]` |
| 关系无法从材料判定 | 知识地图不画这条关系 |
| 插图缺数据 | 不画；否则必须自造数据，而这是禁止的 |
